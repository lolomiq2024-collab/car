# رفيق الطريق الإسلامي — بناء ملف APK عبر GitHub

## الخطوات
1. أنشئ مستودعًا جديدًا على GitHub (يمكن أن يكون خاصًا).
2. ارفع كل محتويات هذا المجلد إلى المستودع (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow**
   (أو يبدأ البناء تلقائيًا عند كل Push على الفرع `main`).
4. بعد نحو 5 دقائق افتح التشغيل المكتمل ونزّل الملف من قسم **Artifacts**:
   `islamic-car-companion-apk` ثم فك الضغط لتحصل على `app-debug.apk`.
5. انقل الملف إلى الهاتف أو شاشة السيارة وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## البنية
- `www/index.html` — التطبيق نفسه
- `capacitor.config.json` — إعدادات التطبيق (الاسم والمعرّف)
- `.github/workflows/build-apk.yml` — سكربت البناء
- مجلد `android/` يُنشأ تلقائيًا أثناء البناء، فلا حاجة لرفعه.

## للتعديل
- غيّر اسم التطبيق أو معرّفه من `capacitor.config.json`.
- أي تعديل على `www/index.html` ثم Push يعيد بناء APK جديد.
